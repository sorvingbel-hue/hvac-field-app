# HVAC — проверка связки (полевое приложение)

PWA для iPhone: выбираешь наружный блок, печь или фанкойл, змеевик и термостат. Приложение показывает СТОП и предупреждения с источником, что добавить в заказ и куда идут провода от термостата.

- Открыть: https://sorvingbel-hue.github.io/hvac-field-app/ → «Поделиться» → «На экран Домой».
- Данные: `data.json` генерируется `tools/export_data.py` из базы `hvac-research/build` (catalog.py, field_rules.py, sources*.py).
- Правила: `rules.js`. Это общий модуль для приложения и для тестов. Тексты и источники берутся только из `data.json`.
- Тесты: `node tests/run.mjs`.
- Модели: `MODELS.md`. Источник на каждый факт (файл и страница): `SOURCES.md`.
- «не проверено» означает, что в документах базы этого факта нет.
